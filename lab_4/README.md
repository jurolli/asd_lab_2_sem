## Лабораторная работа №4

### Реализация красно-черного дерева

#### Постановка задачи:

Реализовать красно-черное дерево с поддержкой основных операций: вставка, удаление, поиск и вывод дерева. Ключом является строка (до 7 символов), значением — вещественное число. Программа должна обеспечивать интерактивное взаимодействие с пользователем через консольные команды.

**Основные операции:**

- Добавление пары (ключ, значение) с автоматической балансировкой дерева
- Удаление узла по ключу с последующей балансировкой
- Поиск значения по ключу
- Вывод дерева в отформатированном виде (с отступами и цветом узлов)

#### Описание реализации:

Дерево реализовано с соблюдением всех свойств красно-черного дерева:

1. Каждый узел имеет цвет: красный (RED) или черный (BLACK)
2. Корень всегда черный
3. Все листья (NIL-узлы) черные
4. У красного узла оба потомка черные
5. Любой путь от узла до листа содержит одинаковое количество черных узлов

**Структура узла:**

```c
typedef struct Node {
    char key[7];        // ключ (строка до 7 символов)
    double value;       // значение
    int color;          // цвет узла
    struct Node *left, *right, *parent;
} Node;
```

#### Ключевые функции:

- insert() — вставка узла с последующей балансировкой
- deleteNode() — удаление узла по ключу
- search() — поиск значения по ключу
- leftRotate() / rightRotate() — повороты для балансировки
- fixInsert() / fixDelete() — восстановление свойств дерева

#### Запуск:

**Сборка программы:**

```bash
gcc -o tree main.c tree.c
```

Запуск с чтением команд из консоли:

```bash
./tree
```

Запуск с чтением команд из файла:

```bash
./tree input.txt
```

#### Команды программы:

| Команда | Формат                | Описание                                  |
| ------- | --------------------- | ----------------------------------------- |
| 1       | `1 <ключ> <значение>` | Добавление значения по ключу              |
| 2       | `2 <ключ>`            | Удаление узла по ключу                    |
| 3       | `3`                   | Вывод дерева (вертикальное представление) |
| 4       | `4 <ключ>`            | Поиск значения по ключу                   |
| 0       | `0`                   | Выход из программы                        |

#### Примеры работы:

**Ввод команд:**

```text

```

Удаление:

