## Лабораторная работа №1

### Динамические структуры данных. Обработка деревьев

#### Постановка задачи:

Составить программу на языке Си для построения и обработки дерева общего вида или упорядоченного
двоичного дерева, содержащего узлы типа iпt. Основные функции работы с деревьями реализовать в виде отдельных
функций. После того, как дерево создано, его обработка должна производиться в режиме текстового меню со
следующими действиями:

- добавление нового узла (для дерева общего вида должен задаваться ро дит ель добавляемого узла. Добавляемый узел становится самым младшим потомком);

- текстовая визуализация дерева (значение каждого узла выводится в отдельной строке, с отступом, пропорциональным глубине узла, в порядке старшинства узлов);

- удаление узла (для дерева общего вида удаляется все поддерево, исходящее из удаляемого узла. Должно быть предусмотрено корректное освобождение памяти);

- определить число вершин дерева, степень которых совпадает со значением элемента;

#### Описание работ:

В лабораторной работе реализовано произвольное дерево, где каждый узел может иметь любое количество потомков. Структура узла содержит указатели на первого потомка (first_child) и следующего брата (next).

_Основные операции:_

- cоздание дерева – задается корневой узел

- добавление элемента – новый узел добавляется в конец списка потомков родителя

- вывод дерева – рекурсивный обход с отступами по глубине

- одсчет вершин – определяется количество узлов, у которых степень (число потомков) равна значению узла

- удаление – рекурсивное освобождение памяти (всего дерева или отдельного узла)

Все операции реализованы рекурсивно. Программа имеет консольный интерфейс и набор тестов для проверки функциональности.

#### Выводы

Реализовано произвольное дерево с операциями: создание, добавление, вывод, подсчет узлов со степенью равной значению, удаление. Изучены понятия дерева, узла, потомка, степени узла. Освоены рекурсивные алгоритмы обхода и работа с динамической памятью в Си.
