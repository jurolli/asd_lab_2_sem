#### Постановка задачи:

Создание синонима всех файлов с указанным суффиксом и числом связей, большим 1, путем
перестановки суффиксов в именах исходных файлов в начало и удаления точки.


#### Описание работы:

Проверяем аргументы, путь к директории и суффикс, введены ли они корректно и существуют ли они. 
Найдем все файлы с этим суффиксом. Потом у каждого найденного файла проверим число связей. 
Если оно больше 1, значит у файла есть хотя бы одна жёсткая ссылка.
Значит для этого файла создаем синонимы. Из исходного имени удаляется суффикс и точка, 
затем суффикс добавляется в начало с символом подчёркивания. Создаем жёсткую ссылку с новым именем.

#### Запуск:

```commandline
./main.bash <директория> <суффикс>
```


#### Примеры работы:

```commandline
./main.bash test txt

```
