## Лабораторная работа №3

### Преобразование арифметических выражений с использованием деревьев

#### Постановка задачи:

Составить программу выполнения заданных преобразований арифметических выражений с применением деревьев. Преобразование выражения в дерево рекомендуется осуществлять одним из известных методов (Дейкстры). Операнды в
обрабатываемых выражениях целого типа. Преобразование выражения реализовать в виде набора подпрограмм. Программа
должна вводить и печатать выражения в исходном (текстовом) виде, преобразовывать их в деревья, выполнять заданные
преобразования путем обращения к подпрограммам и печатать результаты в виде дерева и в текстовом представлении.

**Заменить операцию возведения в степень (`^`) на последовательность операций умножения**

#### Описание работ:

Сначала выполняется разбор строки и построение дерева выражения с использованием алгоритма Дейкстры (два стека: операндов и операторов).

В результате получается бинарное дерево, где:

- листья — числа;
- внутренние узлы — операции.

Далее выполняется преобразование дерева:

1. Выполняется рекурсивный обход дерева.
2. Если встречается узел с оператором `^`:
   - проверяется, что правая часть — число;
   - степень заменяется цепочкой умножений.
3. Левое поддерево (основание х) копируется n раз и связывается цепочкой узлов умножения.
4. Старое поддерево степени корректно удаляется из памяти.

#### Запуск:

Сборка и запуск основной программы:

```commandline
make all
```

Для запуска тестов достаточно:

```commandline
make test
```
