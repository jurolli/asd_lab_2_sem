# Лабораторная работа №5
___

### Графы. Минимальное остовное дерево

**ФИО:** Иващенко Юлия Васильевна  
**Группа:** М8О-102БВ-25
___ 
### Постановка задачи:

Считать и построить неориентированный взвешенный граф с помощью **списка ребер**. После чего с помощью **алгоритма Краскала** и структуры данных **DSU** (система непересекающихся множеств) найти минимальное остовное дерево
### Описание работы:

1. **Представление графа:** Граф хранится как массив структур, содержащих начальную вершину, конечную вершину и вес ребра. Это позволяет эффективно сортировать ребра.
2. **Сортировка:** Все ребра графа сортируются по возрастанию веса. 
3. **Итерация:** Последовательно рассматриваются ребра от самого легкого к самому тяжелому.
4. **Проверка циклов:** С помощью DSU проверяется, лежат ли вершины текущего ребра в одной компоненте связности. Если в разных — ребро добавляется в MST, а компоненты объединяются (используется оптимизация по размеру и сжатие путей).
5. **Завершение:** Алгоритм завершается, когда добавлено V-1 ребро или просмотрены все ребра.

### Запуск:

```bash

make
```

```bash
./lab_5/main
```

```bash
./lab_5/tets
```

